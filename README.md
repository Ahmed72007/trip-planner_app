
# 🌍 Modern Travel Itinerary Planner

A fully functional modern travel itinerary planner mobile app built with Expo, React Native, and TypeScript.

This app helps users organize trips, manage itineraries, create missions/checklists, track travel details, and explore destinations with integrated map and location search features.

## ✨ Features

- 📍 Interactive map integration
- 🔎 OpenStreetMap (OSM) location searching
- 🗺 Google Maps support
- 🧳 Create and manage travel itineraries
- ✅ Mission & checklist management
- 📝 Travel journals and outlines
- 💸 Expense tracking
- 👤 User authentication
- ☁️ Supabase backend integration
- 🌄 Dynamic destination images using Unsplash API
- 🎨 Modern responsive UI using StyleSheet
- ⚡ Fast and optimized Expo workflow

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Ahmed72007/trip-planner_app
````

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npx expo start
```

---

## 🔑 Environment Variables

Create a `.env` file and add:

```env
EXPO_PUBLIC_SUPABASE_URL=YOUR_URL
EXPO_PUBLIC_SUPABASE_ANON_KEY=YOUR_KEY
EXPO_PUBLIC_UNSPLASH_ACCESS_KEY=YOUR_KEY
```
